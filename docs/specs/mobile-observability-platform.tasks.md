## Risks

- **iOS MetricKit does not deliver on the simulator.** T18 verifies with JSON fixtures; device validation is manual before Stage 1.
- **Signal-handler correctness** (async-signal-safe I/O only). Mitigation: preallocated buffer, `write(2)` only, checksum; reviewed in T32.
- **Hermes map composition differs between `expo export` and the native build.** T2 decides the strategy before T14.
- **Percentiles on large tables.** Mitigation: composite indexes `(project_id, name, ts)`; daily rollups only if T34 fails the budget.

## Rollout and rollback (user-facing)

- Dashboard: Stage 0 local, then a deploy target per OQ-5. Rollback means redeploying the previous build; migrations are expand-only per release.
- SDK: `0.1.0-beta` on npm `next`, then `1.0.0`. Rollback means the kill switch (T29), or an OTA update pinning the previous SDK JS; a native change needs a new build.
